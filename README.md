# 🤖 Robot Path Finder

## About
Robot Path Finder is a C-based project that finds a path from a starting point to a destination while avoiding obstacles on a grid.

## Algorithms
- **BFS:** Uses a queue to find the shortest path in an unweighted grid.
- **DFS:** Uses a stack to explore paths through the grid.
- **A\* Search:** Uses a heuristic to guide the search.

## Technologies
- Language: C
- IDE: Visual Studio Code
- Concepts: Arrays, queues, stacks and graph traversal.

## Features
- Grid and obstacle representation
- Starting point and destination selection
- Pathfinding using BFS and DFS
- Path reconstruction
- Algorithm comparison (planned)

## How to Run
Compile using GCC:

```bash
gcc main.c -o robot_path_finder
```

Run on Windows:

```bash
.\robot_path_finder.exe
```
